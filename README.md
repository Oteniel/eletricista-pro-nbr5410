# Eletricista Pro - NBR 5410

Aplicacao profissional para dimensionamento eletrico residencial conforme a **NBR 5410:2004**.

## Funcionalidades

### Calculadora Rapida
- **Troca de Cabo** - Descubra a bitola correta a partir da potencia do equipamento
- **Disjuntor Desarmando** - Valide se o disjuntor esta correto para a carga

### Projeto Completo
- Dimensionamento guiado passo a passo
- Suporte a instalacoes monofasicas, bifasicas e trifasicas
- Calculo automatico de bitolas e disjuntores
- Compartilhamento via WhatsApp

### Novidades v7.0
- Projetos salvos automaticamente no celular (localStorage)
- Funciona 100% offline - sem necessidade de internet
- App instalavel como APK Android
- Validacao de inputs para evitar erros
- Service Worker melhorado para cache robusto

## Como Usar

### Opcao 1: APK Android (Recomendado - Offline)
1. Instale o APK no seu celular Android
2. Abra o app - funciona sem internet!

### Opcao 2: Servidor Local (Rede Wi-Fi)
```bash
# Entre na pasta do projeto
cd eletricista-pro-nbr5410

# Inicie o servidor
python servidor.py

# Acesse no navegador do celular
http://SEU_IP_LOCAL:8765
```

### Opcao 3: PWA (Navegador)
1. Abra no Chrome
2. Toque em **Adicionar a tela inicial**
3. O app funciona offline apos o primeiro acesso
