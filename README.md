# ⚡ Eletricista Pro - NBR 5410

Aplicação web profissional para dimensionamento elétrico residencial conforme a **NBR 5410:2004**.

## 📋 Funcionalidades

### Calculadora Rápida
- **Troca de Cabo** - Descubra a bitola correta a partir da potência do equipamento
- **Disjuntor Desarmando** - Valide se o disjuntor está correto para a carga

### Projeto Completo
- Dimensionamento guiado passo a passo
- Suporte a instalações monofásicas, bifásicas e trifásicas
- Cálculo automático de bitolas e disjuntores
- Compartilhamento via WhatsApp

## 🚀 Como Usar

### Executar localmente

```bash
# Entre na pasta do projeto
cd "D:\Automação Residencial\Projetos\Eletricista-Pro-NBR5410"

# Inicie o servidor
python -m http.server 8765

# Acesse no navegador
http://localhost:8765
```

## 📱 Instalar como App (PWA)

No celular:
1. Abra no Chrome
2. Toque em **⋮** (menu)
3. Toque em **"Adicionar à tela inicial"**
4. Confirme a instalação
