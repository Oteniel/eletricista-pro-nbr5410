# Eletricista Pro - NBR 5410

## Como usar no celular

### Opcao 1: APK Android (Recomendado - 100% Offline)
1. Execute: `gerar_apk.bat`
2. Siga as instrucoes na tela
3. Instale o APK no celular
4. Pronto! Funciona sem internet

### Opcao 2: Copiar para o celular
1. Copie TODA a pasta `eletricista-pro-nbr5410` para o celular
2. No celular, abra o arquivo `index.html` com o Chrome
3. Funciona offline!

### Opcao 3: Via Wi-Fi (mesma rede)
1. Execute: `abrir_app.bat` ou `iniciar.bat`
2. No celular, acesse o IP mostrado na tela
3. Celular e computador devem estar na mesma rede Wi-Fi

## Arquivos importantes

- **abrir_app.bat** - Abre o app no navegador do computador
- **iniciar.bat** - Inicia o servidor para acesso via Wi-Fi
- **iniciar_silencioso.vbs** - Inicia o servidor sem janela (segundo plano)
- **gerar_apk.bat** - Gera o APK Android para instalacao offline
- **parar_servidor.bat** - Para o servidor
- **INSTALACAO_MOBILE.md** - Instrucoes detalhadas para mobile

## Se o IP mudar

Se o IP do computador mudar, descubra o novo IP:
1. Abra o terminal (cmd)
2. Digite: `ipconfig`
3. Procure por "Endereco IPv4" na sua conexao Wi-Fi
4. Use o novo IP no celular: `http://NOVO_IP:8765`

## Dica

Para acessar mais facilmente no celular, salve o endereco como favorito no navegador.
